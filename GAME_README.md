# 🕹 SSC Clicker - Telegram Web App Game

Полнофункциональная телеграм игра-кликер с современным дизайном и увлекательной механикой!

## 🎮 Особенности игры

### Основная механика
- **Кликер с анимацией** - тапайте по золотой монете SSC и зарабатывайте очки
- **Система энергии** - 10,000 энергии в день (30,000 для VIP)
- **Комбо-множители** - до 1.5x при быстрых кликах (20+ кликов за 7 сек)
- **Звуковые эффекты** - 5 случайных звуков клика + фоновая музыка

### Разделы игры

#### 🏠 Главная
- Центральная монета с анимацией bounce при клике
- Счетчик кликов (отображается полными числами)
- Полоса энергии с градиентом
- Кнопки "Join Squad" и "Leader" по центру

#### 👥 Друзья
- Реферальная система (+500 SSC обычный, +2500 SSC Premium)
- Система подарков (1500 энергии за 10 Telegram Stars)
- Счетчик отправленных подарков (0/3 в день)
- Список друзей с онлайн статусом

#### 🎮 Игры
- **Sheep Runner** - мини-игра с случайными наградами
- Награды: 1-1500 SSC, 1-2500 энергии, x3 буст на 5 минут
- До 5 игр в день

#### 🛒 Магазин
- **Бусты** - увеличивают SSC за клик
- **Автомайнинг** - пассивный доход (до 15 уровней)
- **Скины** - кастомизация (в разработке)
- **VIP подписка** - 999 Stars (скидка с 1500)

#### 💰 Заработок
- TON кошелек (+1000 SSC за подключение)
- Ежедневные бонусы (7 дней)
- Достижения с прогресс-барами
- Социальные сети

#### 👤 Профиль
- Статистика игрока
- VIP статус с короной
- Количество кликов, SSC, друзей
- Дата регистрации

#### ⚙️ Настройки
- Переключение языка (RU/EN)
- Управление звуками и музыкой
- Уведомления
- Тёмная тема

## 🎨 Дизайн

### Цветовая схема
- **Основной**: Золотой градиент (#FFAA00)
- **Вторичный**: Фиолетовый (#9333EA) 
- **Акцент**: Голубой (#00D4AA)
- **Энергия**: Зелёный (#00FF00)
- **Фон**: Тёмная тема с градиентными акцентами

### Анимации
- Bounce эффект при клике на монету
- Ripple эффект с кругами
- Glow анимации для важных элементов
- Плавные переходы между страницами

## 🔧 Технологии

- **React 18** + TypeScript
- **Tailwind CSS** с кастомной дизайн-системой
- **Shadcn/ui** компоненты
- **Контекстное управление состоянием**
- **LocalStorage** для сохранения прогресса
- **Responsive дизайн**

## 📱 Интеграция с Telegram

### Необходимые функции бота:
1. **Авторизация** через Telegram WebApp
2. **Реферальная система** - генерация ссылок
3. **Платежи** через Telegram Stars
4. **Push-уведомления**
5. **Данные пользователя** (аватар, имя, Premium статус)

### Backend функции (через Supabase):
- Сохранение прогресса игрока
- Реферальная система
- Лидерборды и кланы
- Система достижений
- Платежи и транзакции
